☁️ Cloud To-Do List

A cloud-based task management application built using HTML, JavaScript, and Firebase Realtime Database. The application allows users to add and delete tasks while storing data securely in the cloud with real-time synchronization.

📌 Overview

Cloud To-Do List helps users organize their daily activities efficiently. By leveraging Firebase Realtime Database, tasks are stored online and updated instantly, providing a simple example of a cloud-enabled web application.

🚀 Features

- Add new tasks
- Delete existing tasks
- Real-time cloud synchronization
- Instant updates using Firebase
- Simple and user-friendly interface

🛠️ Tech Stack

- HTML
- JavaScript
- Firebase Realtime Database
- Cloud Computing
